# 友情任務版本2｜第一關示範版

適合五年級兩人共用 iPad，建議橫向遊玩。

流程：六人選角 → 雙人確認 → 第一關完整對話 → 雙人練習 → 回憶頁。

- 六個固定角色，每人選擇不同角色；可交換行動者與友情偵探。
- 使用六張選角頭像、六張基本立繪與教室場景。
- 第一關含四種開場、四種偏好、四種接話，以及重試與角色吊飾回應。
- 回憶頁記錄本次選擇，可下載 PNG、交換角色重玩或重新選角。
- 目前使用基本立繪，尚未增加各種表情；重新整理會重置進度。
- 教師設定可調整討論秒數。不錄音、不評分。

本資料夾為獨立示範版，根目錄保留版本1七關遊戲。

## 六人劇情更新

兩位玩家選中的角色直接成為對話搭檔。六條路線有各自的內心話、開場、興趣分享、邀請與結尾。開場也會依另一位角色的道具改變。

- 玩家1站左側、玩家2站右側；換任務不更換玩家化身。
- 每張基本與開心立繪分別記錄原始面向，依站位轉向中央。
- 新增六張開心說話立繪，基本聆聽與開心回應依情節切換。
- 不同意聊成績等分支回到接話選擇，尚未增加專用難過或疑惑表情。
- 回憶頁和PNG都記錄本次路線與共同邀請。

驗證：30種配對的完整流程，另檢查交換任務後的960個畫面，包括身份、站位、面向、素材及說話者。
