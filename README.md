# 友情任務｜新朋友大挑戰 · 版本1

適合國小五年級的雙人友情網頁遊戲。兩人共用一台 iPad，透過故事、選擇、討論與真人練習，學習與朋友相處。

## 遊戲內容

1. 勇敢開口
2. 我可以一起玩嗎？
3. 喜歡不一樣，也能聊
4. 聊天卡住了
5. 表情偵探
6. 他拒絕我了
7. 最終挑戰：友情交換條件

包含角色左右對話、手繪校園場景、關卡地圖、雙人輪流操作，以及可下載圖片的友情工具箱。

## 課堂操作

- 建議橫向使用，每關約 5–8 分鐘，可直接選關。
- 各自選擇時，另一位先轉身；一起揭曉後輪流說明想法。
- 教師設定可調整討論時間及音效。
- 不登入、不錄音；重新整理會清除本次暱稱、選擇與進度。
- 完成標記代表練習紀錄，不評定交朋友的能力。

## 版本紀錄

此專案保存版本1（v1.0.0），遊戲檔案與原版本1快照一致，不含版本2企畫中的人物客製化功能。

純靜態 HTML、CSS、JavaScript，無需安裝套件或建置。GitHub Pages 從 main 分支根目錄提供網站。
